# UI大規模改修 実装計画

## 概要
左サイドバー（大分類タブ）＋各画面上部タブ（小分類）の2段構成UIに移行し、
各画面のモーダル化・編集機能追加・カレンダーUI化を実施する。

## 変更ファイル一覧

### [MODIFY] style.css
- サブタブ（上部タブバー）のスタイル追加
- モーダルの汎用スタイル強化（幅広いモーダル対応）
- カレンダー用スタイル追加
- タグバッジ（活動項目カテゴリー表示）スタイル追加

---

### [MODIFY] index.html
各セクションのHTML構造を全面的に再構成：
- **予算管理**: サブタブ「交付金収受」「予算設定」に分割、支出実績を実績記録タブへ移動
- **単価・設定**: サブタブ「組織情報」「単価マスタ」「地区・名簿」「活動項目」に分割
- **物品管理**: サブタブ「物品台帳」「入出庫ログ」に分割
- **作業計画**: 大型カレンダービューに変更
- **実績記録**: サブタブ「作業実績」「支払実績」に分割
- 各種モーダルHTML追加

---

### [MODIFY] src/js/budget.js
- `render()` を各サブタブに対応した描画に更新
- 交付金収受フロー：編集ボタン追加（モーダルで編集）
- 支出実績の表示を record.js 側へ委譲

### [MODIFY] src/js/master.js
- `render()` を大規模改修
  - 組織情報：現在値を表示 → 「編集」ボタンでモーダル表示
  - 単価マスタ：現在値を表示 → 「編集」ボタンでモーダル表示
  - 地区マスタ：一覧表示 → 地区ごとに編集ボタン
  - 活動項目：カテゴリーボタン（藻場/干潟）→ クリックでモーダル内チェックリスト

### [MODIFY] src/js/inventory.js
- `render()` を改修
  - 物品台帳：編集ボタン追加
  - 入出庫ログ：編集ボタン追加
  - 新規物品登録・入庫登録をモーダル化

### [MODIFY] src/js/plan.js
- `render()` を大型カレンダー表示に全面改修
  - 月選択ナビゲーション
  - カレンダーグリッド（曜日ヘッダー + 日付セル）
  - 日付クリックでモーダルを表示 → モーダル内で計画登録
  - 既存の計画はカレンダー上にバッジ表示

### [MODIFY] src/js/record.js
- `render()` を改修
  - サブタブ「作業実績」「支払実績」を切替可能に
  - 作業実績：編集ボタン追加（モーダルで編集）
  - 支払実績（旧「支出実績」budget.jsから移動）：編集ボタン追加

### [MODIFY] src/js/navigation.js
- サブタブの初期化処理を追加

## 実装順序
1. style.css（サブタブ・カレンダー・モーダルCSS追加）
2. index.html（HTML構造再構成・モーダルHTML追加）
3. budget.js（render改修・編集機能）
4. master.js（render改修・全面モーダル化）
5. inventory.js（render改修・モーダル化・編集機能）
6. plan.js（カレンダーUI）
7. record.js（サブタブ化・支払実績移管・編集機能）
8. navigation.js（サブタブ対応）

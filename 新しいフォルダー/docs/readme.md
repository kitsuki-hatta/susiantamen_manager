# 漁場生産力・水産多面的機能強化対策 活動管理システム

大分県内の藻場・干潟保全活動に取り組む活動組織向けの、ブラウザーで動作する運用管理アプリです。活動組織ごとに予算、作業計画、実績、物品、支払、潮位データを管理し、報告書（様式1〜6）を作成できます。

## 主な機能

- **複数活動組織**: ヘッダーの組織選択で切り替え、組織追加から新しい組織を登録できます。組織の業務データとIndexedDB作業データは組織単位で分離されます。
- **ダッシュボード**: 予算執行、計画・実績・支払状況、アラートを確認できます。
- **はじめてガイド**: 初期設定・予算・計画・実績・バックアップの進み具合を表示し、各画面へ移動できます。完了状態は現在の登録データから判定します。
- **年度ふりかえり**: 年度ごとの活動日数、実績件数、延べ参加人数、計画件数、活動項目、写真をまとめて確認し、印刷またはPDF保存できます。
- **活動バッジ**: 初回計画・実績、記録10件、藻場と干潟の実施、写真、バックアップを達成表示します。競争・順位付けや公式集計への利用はありません。
- **予算管理**: 交付金収受、採択予算額、期別の執行計画額を管理します。
- **単価・設定**: 組織情報、賃金方式と単価、地区・名簿、使用する藻場・干潟活動項目、潮位データ等を管理します。
- **物品管理**: 物品台帳、入出庫、購入記録等を管理します。
- **作業計画**: カレンダーで計画を登録・編集・削除します。日付クリックで潮位グラフを固定し、日付ダブルクリックで新しい計画を入力できます。グラフ上のカーソル位置に時刻・潮位を表示し、当日の実績時間帯を緑色で重ねます。
- **実績記録・支払先集計**: 作業実績、参加者、費用、支払状況を記録・確認します。
- **報告書出力**: 様式1〜6を作成し、対応する帳票を出力できます。活動分類は活動コードを基準に判定します。
- **バックアップ・復元**: フルJSON／軽量CSVの出力、フルJSONの復元、IndexedDB作業データのJSON入出力、ストレージ使用量の確認、日付別作業データの削除を利用できます。
- **ヘルプ・使い方**: 初心者向けの利用手順、各画面の概要、注意事項、緊急時の連絡先をアプリ内で確認できます。
- 主要な一覧やグラフが空の場合は、次にできる操作や入力画面への案内を表示します。
- 画面上部のヘッダーとサイドバーは固定され、本文領域をスクロールして画面を移動します。

## 動作環境と起動

- モダンなデスクトップブラウザーを推奨します。Excel帳票の作成には同梱のExcelJSを使用します。
- サーバーは必須ではありません。プロジェクト直下の `index.html` をブラウザーで開いてください。
- 画像選択、フォルダーへのバックアップ保存など一部機能はブラウザーの権限・実行環境に依存します。必要に応じてローカルWebサーバー経由で起動してください。
- 保存先フォルダーを記憶してJSON／CSVを書き込む機能はFile System Access API対応ブラウザーで利用できます。未対応・権限失効時は通常のダウンロードに切り替わります。

## データ保存とバックアップ

- 通常の業務データはブラウザーの `localStorage` に保存されます。標準の `moba_` キーを使用し、追加組織は組織IDを含むキー名前空間に保存します。従来の既定組織データはそのまま利用します。
- 日々の作業データと写真等の画像Blobは組織別のIndexedDBに保存します。旧形式データは初期化時に移行し、既存画面との互換性のため一部データはlocalStorageにも参照情報・ミラーとして保持します。
- 画像は保存時に縮小・圧縮されます。ブラウザーや端末の空き容量に左右されるため、一定期間・件数の保存を保証するものではありません。
- **フルバックアップ(JSON)** は現在の組織データとIndexedDB作業データを含み、復元に使用します。復元はデータを上書きします。同じ活動組織のバックアップを選び、復元前に現在のデータも保存してください。
- **CSVバックアップ** は表計算ソフト等で確認するための軽量出力で、フルJSONの代替復元データではありません。
- **作業データJSON** はIndexedDBの日付別データの書き出し・復元用です。組織別データのため、対象組織を確認して利用してください。
- バックアップは定期的に作成し、アプリと同じブラウザーの保存領域だけでなく、別の安全な場所にも保管してください。端末間の自動同期はありません。

## プライバシーと制約

- データは利用中のブラウザー／端末に保存されます。認証、ユーザー権限、暗号化、複数ユーザー同時編集、端末間同期は実装していません。
- ブラウザーのデータ消去や端末故障でデータが失われる可能性があります。バックアップを定期的に作成してください。
- 旧アサリ版アプリとのデータ自動連携・移行はありません。

# 地理院タイル同梱手順（bundled モード）

## 1. 前提
- 位置図で同梱タイルを使う場合は、運用前に利用条件を確認してください。
- 出典表記は画面・出力に必須です（本アプリは出典描画を実装済み）。

## 2. 配置規約
- 推奨パス: assets/gsi_tiles/{org_id}/{z}/{x}/{y}.png
- フォールバック: assets/gsi_tiles/default/{z}/{x}/{y}.png
- 対象ズーム: 14-18
- 推奨形式: PNG

### org_id の決まり方
- アプリは組織情報から org_id を自動生成して参照します。
- 値の候補: orgId / orgCode / code / orgName（英小文字 + 記号は `_` に正規化）
- 例: `大分市保全協議会` -> `oita_shinko`（運用で任意に調整）

## 3. 取得範囲の決め方
1. 対象市町村（設定タブ）を中心点にする。
2. 活動海域を覆うように、各ズームで必要タイル範囲を算出する。
3. 不要な広域を避け、活動範囲周辺に限定して取得する。

## 4. 配置手順
1. z ごとに x/y フォルダ構造を作成する。
2. 取得したタイルを {y}.png 名で配置する。
3. アプリの設定で mapTileMode を bundled に切り替える。
4. 様式5の位置図で表示確認する。

## 5. 欠損時の挙動
- 対象タイルが存在しない場合、プレースホルダ（格子+タイル座標）が表示されます。
- org_id 側に無い場合は `default` フォルダをフォールバック参照します。
- 欠損タイルを追加配置すると再描画で反映されます。

## 6. GeoJSON 運用メモ
- 協定範囲は GeoJSON（Polygon/MultiPolygon）を利用します。
- Shapefile を使う場合は事前に GeoJSON に変換してください（QGIS等）。
- 座標系は WGS84（EPSG:4326）前提です。
